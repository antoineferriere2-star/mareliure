## Défauts trouvés et corrigés (PR de cet audit)

1. `/reliure` répondait 200 sur les deux domaines, double de l'accueil Ma Reliure : redirigé en 301 vers `https://mareliure.fr/`.
2. `/professionnels`, ancien annuaire « FineBindery », répondait 200 indexable sur les deux domaines, hors sitemap : 301 vers `https://finebindery.com/fr/professionals`.
3. `/fine-bindery`, ancien lien de prévisualisation : 301 vers `https://finebindery.com/en`.
4. `/conditions-ateliers` était indexable sans canonical ni description, sur les deux domaines, titré « — Oppe » : rattaché à Ma Reliure (301 depuis finebindery.com), canonical et description ajoutés.
5. `/{langue}/project` (Fine Bindery, `noindex`) portait la description anglaise du site dans toutes les langues : titre, description, canonical et hreflang de la langue de la page.

Les redirections vivent dans `LEGACY_PAGE_REDIRECTS` (`src/marketplace/brand/brandPages.ts`), appliquées par `canonicalRedirectUrl` aux seuls domaines connus.

## Constats laissés en l'état

- `/demo/deck-project` (démonstration Métré Build) répond 200 sur les deux domaines : `noindex`, rendu côté navigateur seulement, puis renvoi vers Métré. Sans effet sur l'indexation.
- `/a/:slug`, `/ateliers/:slug`, `/auth` : `noindex`, voulu.
- Pages légales Fine Bindery en anglais seulement (`lang=en`) : acceptable, à traduire si le trafic non anglophone le justifie.
- `/legal-notice` : description de 57 caractères, sans incidence.
- Annuaire Fine Bindery vide (`noindex`) tant que le profil de Reliure Ferrière n'est pas publié : c'est le principal manque de contenu indexable de Fine Bindery.
